# Sample input: fictional brand

This example is fictional and contains no client data.

```text
Run a Creative Audit for Northstar Hydration, a fictional electrolyte powder.

Market: United States
Language: English
Hero product: Daily Hydration Sachets
Channel: Meta
Use public independent category evidence only. Because the brand is fictional, do not invent brand reviews, ads, performance, customers, or reputation signals.
Deliver: diagnostic report, persona and awareness gaps, diversity review, five direct category competitors, 3 priority concepts, and a 90-day roadmap.
```

The correct audit must clearly distinguish category hypotheses from brand-specific observations and mark the brand ad sample as unavailable.
